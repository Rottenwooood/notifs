约束清单

项目：notifs 代码包导出　阶段：bundle-export

约束

编号约束
C1范围是把提交 HEAD 的被跟踪文本文件按依赖顺序导出为单个纯文本文件。不做源码修改、不加测试、不改接口，不把未跟踪的构建产物、锁文件、生成稿与历史机器日志写入产物。
C2产物为仓库内可复用的导出脚本 tools/export-codebase.mjs，以及仓库外的 /home/c6h4o2/exports/notifs-codebase-<提交>-<日期>.txt。
C3验收标准是往返还原：从产物逆解析出的每个文件与 git show 的字节完全相等；产物路径集合等于被跟踪文件减去排除清单；正文行数与头部声明一致；产物与工作区均无凭据。
C4允许 git ls-files、git show、git rev-parse、node、wc、sha256sum、secrets-audit.sh、git 本地提交、timeout。
C5不 push、不 reset --hard、不改写历史、不使用 pkill -f 或 killall、不回显凭据、不删除任何被跟踪文件、不改动用户正在运行的服务。
C6预算 30 分钟；导出脚本单次运行不超过 10 秒；产物不超过 400 KB；不产生长期运行进程。

范围

做

  • 按依赖方向排列全部被跟踪源码、配置、测试、文档
  • 头部给出提交、文件数、行数、排除清单与行号索引
  • 往返还原校验与密钥扫描

不做

  • 源码与接口变更
  • 锁文件、构建产物、生成稿、历史机器日志
  • 提交产物到仓库

编号路径形态
