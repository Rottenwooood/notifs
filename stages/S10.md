# S10

## 1 开头

notifs 是单节点、自托管、以身份与订阅为核心的通信中心；当前阶段 S10 修复外部代码审计确认的投递与入口缺陷：调度器忽略 `retryable`、飞书私聊被过滤、CLI 无值开关吞参数、适配器不响应停止信号等。
下一阶段入口：决定是否落地 `last_error` 与 held 查询接口、凭据解析白名单两项（它们改 schema 与安全策略，见本节末尾说明）。

## 3 本阶段约束

- C1 只修审计确认的六项缺陷，不碰 schema 与凭据策略。
- C2 产物覆盖 contracts/store/core 的内部操作、调度循环、5 个适配器、CLI 与测试。
- C3 验收要求 held、退避、私聊入站、CLI 开关在真实进程上可观察。
- C4 只用隔离目录与端口，不触碰生产 relay。
- C5 不 push、不回显凭据、不用 pkill 家族。
- C6 预算 120 分钟，不新增依赖，不扩公共路由与工具集。
